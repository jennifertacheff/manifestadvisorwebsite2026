# Homepage logo assets

Downloaded SVG provenance is recorded in sources.json. Existing project assets are reused for GoFundMe, SXSW, Women Who Code, Techstars, and Onramp. Techstars and Onramp currently use PNG originals. The Go Game uses the official PNG wordmark from its website; the previously downloaded SVG was decorative artwork and has been removed.

The following entries deliberately use plain text rather than unverified or fabricated logos: W Fund, Plaid Matrix Fund (one organization, confirmed by the user), DeepMind, Collective Impact, Noesis Collaborative, The Connection Institute, and BIP Ventures. Replace their text in index.html when approved SVG artwork is available.

EU Digital uses the European Commission mark from its Digital Strategy website. All downloaded artwork is displayed monochrome via CSS; original files retain their colors.
